## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **No packets captured** | Check NIC + mirror |
| **Nmap blocked** | Disable firewall |
| **Wireshark slow** | Add filters |
| **GNS3 won't start** | Check VM support |
| **DNS not resolving** | Check resolv.conf |
| **Permission error** | Run as admin |
